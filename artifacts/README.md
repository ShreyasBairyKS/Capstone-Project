# Final Capstone Planning Artifacts

This folder contains the final-phase planning artifacts for **VisionFood QAI**:

- `work_breakdown_structure.md` — deliverable-oriented WBS with hierarchical IDs, accountable owners, estimates, and acceptance evidence.
- `updated_gantt_chart.md` — baseline-versus-actual Gantt, dependencies, progress, and risk-adjustment register.

## Scope boundary

These artifacts cover the final capstone implementation and its evidence package: bottle-cap detection/segmentation, cap-classifier prototype artefacts, fill-level estimation, dashboard visualisation, Himalaya-label defect detection, integration/deployment evidence, and final technical documentation. The Himalaya work is included in the final report/thesis scope, but is explicitly excluded from the research-paper experimental scope. Untraceable classifier benchmark and latency claims are future evaluation work.
