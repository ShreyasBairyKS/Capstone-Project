\section{Lessons Learned and Conclusion}
\textbf{What worked.} Clear ownership: each package had one owner, and work rarely collided (Table 3.4). Trying a baseline before committing: the label line moved to EfficientAD on evidence from crop tests, not preference (CR2, CR3). Building a stable test script per layer let the late Station 2 merge land without disturbing Station 1.

\textbf{What we would do differently.} Keep a simple weekly log from day one; this report had to reconstruct what ten minutes a week would have recorded. Set scope from available data, not ambition (Section 7.2). Test deployment on the target GPU much earlier: P's 26-day slip (Table 4.4) came from issues that an early trial could have found while the path still had time.
