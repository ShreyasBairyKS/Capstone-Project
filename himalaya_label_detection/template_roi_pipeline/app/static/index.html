    How to read this page
    1. Find the regions. Each of the four label regions has a stored template. Template matching locates the best complete copy of it on the scan.
    2. Score each region. The crop (turned upright, as the models were trained) goes to that region's own anomaly model. The model returns a map; the score is the average of the map.
    3. Compare with the limit. A region fails when its score is above its calibrated limit. The label passes only if all four regions pass and all four were found.
    4. Heat views. Above limit tints only pixels the model scores above the limit; stronger colour means further above. Numbered boxes mark the strongest regions, and the text says how much each one adds to the score and what the score would be without it. Full map is a relative view that always highlights the hottest place, even on a clean crop, so use it to explore, not to judge.

    Heatmaps explain where the model reacted; they do not prove a defect is physically there. Treat a flagged region as the place to look first.
